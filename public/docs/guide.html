Mi az etikus tesztelés?

Az etikus hacking azt jelenti, hogy saját engedélyeddel teszteled egy rendszer biztonságát. Célja a gyengeségek megtalálása, mielőtt egy rosszindulatú támadó megtenné.

Csak olyan rendszert tesztelj, amelyhez írásban megkaptad az engedélyt, vagy a saját tulajdonod!

Jogi háttér (Magyarország)

Magyarországon a Btk. 375-376. §-a szabályozza az informatikai bűncselekményeket. Más hálózatán való engedély nélküli tesztelés büntetőjogi következményekkel jár.

Biztonságos gyakorlás: otthoni labor (Raspberry Pi, VM-ek) vagy CTF platform!

WiFi biztonsági szintek

  • WEP – Elavult RC4 alapú, percek alatt törhető
  • WPA – Már elavult, sebezhető
  • WPA2 – AES alapú, erős jelszóval biztonságos
  • WPA3 – SAE protokoll, legjobb védelem

A wifite ezek gyengeségeit teszteli automatikusan.

Fontosabb portok

  • 22 – SSH (biztonságos távelérés)
  • 80 – HTTP (titkosítatlan web)
  • 443 – HTTPS (titkosított web)
  • 445 – SMB (Windows megosztás ⚠️)
  • 3389 – RDP (Windows távoli asztal ⚠️)

Az nmap megmutatja, melyik nyitott nálad.

Következő lépések

  • TryHackMe – interaktív oktatás kezdőknek
  • Hack The Box – haladó kihívások, iparági standard
  • OWASP – webes biztonsági alap
  • Kali Linux – pentest disztribúció
  • CEH / OSCP – elismert tanúsítványok

Telepítés

Ubuntu/Debian/Kali
sudo apt update && sudo apt install wifite nmap
sudo npm start
macOS (Homebrew)
brew install nmap
sudo npm start # wifite macOS-en nem elérhető
