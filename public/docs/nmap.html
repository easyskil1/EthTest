Host Discovery (-sn)

Az Nmap nem csak egyszerű pinget küld. Helyi hálózaton ARP requesteket használ – ez kikerülhetetlen, mert az OS-nek szüksége van a MAC-re a kommunikációhoz. Távoli hálózaton négy próbát tesz egyszerre:

  • ICMP Echo Request (hagyományos ping)
  • TCP SYN a 443-as portra
  • TCP ACK a 80-as portra
  • ICMP Timestamp Request

TCP SYN Scan (-sS) – Stealth mód

A legelterjedtebb technika. Elküldi a SYN flag-et:

  • SYN/ACK visszajön → port OPEN
  • RST/ACK visszajön → port CLOSED

Az Nmap azonnal RST-t küld vissza – a teljes kapcsolat sosem épül fel. Sok régi naplózó ezért nem észleli.

UDP Scan (-sU)

Az UDP protokollnak nincs állapota. Ha csomagot küldünk:

  • Port ZÁRVA → ICMP Port Unreachable (Type 3, Code 3)
  • Port NYITVA → sokszor semmi válasz → open|filtered
UDP scan rendkívül lassú, mert a routerek korlátozzák az ICMP válaszok sebességét (Rate Limiting).

NSE – Nmap Scripting Engine

Lua nyelven írt scriptek. Fontosabb kategóriák:

  • vuln – CVE-k keresése (pl. EternalBlue: smb-vuln-ms17-010)
  • brute – jelszópróbálgatás (FTP, SSH, HTTP-form)
  • discovery – DNS zónatranszfer, SNMP tartalom
  • auth – alapértelmezett hitelesítő adatok keresése
  • malware – backdoor nyomok keresése

Timing Templates (-T0 – -T5)

  • -T0 Paranoid – percek soronként, IDS-t altat
  • -T1 Sneaky – rendkívül lassú
  • -T3 Normal – alapértelmezett
  • -T4 Aggressive – gyors, CTF-re ajánlott
  • -T5 Insane – leggyorsabb, pontatlanabb

Tűzfal és IDS kikerülés

  • -f – Fragmentation: TCP fejléc apró csomagokra bontva
  • -D decoy1,decoy2 – Decoys: hamis forrás IP-k keveréke
  • -sI zombie_ip – Idle Scan: zombi gép IP-jén keresztül
