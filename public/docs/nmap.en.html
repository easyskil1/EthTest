Nmap Deep Dive

Host Discovery (-sn)

Nmap doesn't just send a simple ping. On a local network it uses ARP requests — unavoidable because the OS needs the MAC address to communicate. On remote networks it tries four probes simultaneously:

  • ICMP Echo Request (traditional ping)
  • TCP SYN to port 443
  • TCP ACK to port 80
  • ICMP Timestamp Request

TCP SYN Scan (-sS) – Stealth mode

The most common technique. Sends the SYN flag:

  • SYN/ACK returned → port OPEN
  • RST/ACK returned → port CLOSED

Nmap immediately sends back RST — the full connection is never established. Many older loggers therefore don't detect it.

UDP Scan (-sU)

The UDP protocol is stateless. When a packet is sent:

  • Port CLOSED → ICMP Port Unreachable (Type 3, Code 3)
  • Port OPEN → often no response → open|filtered
UDP scan is extremely slow because routers limit ICMP response rates (Rate Limiting).

NSE – Nmap Scripting Engine

Scripts written in Lua. Major categories:

  • vuln – CVE detection (e.g. EternalBlue: smb-vuln-ms17-010)
  • brute – password guessing (FTP, SSH, HTTP-form)
  • discovery – DNS zone transfer, SNMP content
  • auth – searching for default credentials
  • malware – searching for backdoor traces

Timing Templates (-T0 – -T5)

  • -T0 Paranoid – minutes per line, puts IDS to sleep
  • -T1 Sneaky – extremely slow
  • -T3 Normal – default
  • -T4 Aggressive – fast, recommended for CTF
  • -T5 Insane – fastest, less accurate

Firewall and IDS evasion

  • -f – Fragmentation: TCP header split into tiny packets
  • -D decoy1,decoy2 – Decoys: mix of fake source IPs
  • -sI zombie_ip – Idle Scan: via the IP of a zombie machine
These should only be used on authorized engagements!
