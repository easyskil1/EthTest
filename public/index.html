⚡ Wifite Konfiguráció

Mi ez?
A wifite egy automatizált WiFi biztonsági tesztelő eszköz.

⚠️ Fontos: Csak saját hálózaton használd!
Rendszerkövetelmények
● Linux (Kali / Parrot / Ubuntu) – teljes támogatás
● macOS – wifite nem elérhető, nmap igen
● Monitor módot támogató WiFi kártya
● Root jogosultság (sudo npm start)

📋 Port Referencia

Még nincs scan előzmény.
Mi ez?
Az nmap (Network Mapper) megvizsgálja, hogy egy hálózaton milyen gépek és nyitott portok vannak. Segít megérteni, mit "lát" egy külső szemlélő a hálózatodról.
Telepítés
sudo apt install nmap (Linux)
brew install nmap (macOS)
Általános portok
21 – FTP
22 – SSH
23 – Telnet
25 – SMTP
53 – DNS
80 – HTTP
110 – POP3
143 – IMAP
443 – HTTPS
445 – SMB ⚠️
3306 – MySQL
3389 – RDP ⚠️
5432 – PostgreSQL
6379 – Redis
8080 – HTTP alt
8443 – HTTPS alt

📖 Kezdők útmutatója

🛡️

Mi az etikus tesztelés?

Az etikus hacking azt jelenti, hogy saját engedélyeddel teszteled egy rendszer biztonságát.

Arany szabály: Csak saját rendszert tesztelj!
⚖️

Jogi háttér (Magyarország)

Magyarországon a Btk. 375-376. §-a szabályozza az informatikai bűncselekményeket.

Biztonságos gyakorlás: Használj otthoni labort!
📡

WiFi biztonsági szintek

  • WEP – Elavult, percek alatt törhető. Ne használd!
  • WPA – Már elavult, sebezhető.
  • WPA2 – Elterjedt, erős jelszóval biztonságos.
  • WPA3 – Legújabb, legjobb védelem.

A wifite ezek gyengeségeit teszteli.

🔌

Fontosabb portok

  • 22 – SSH (biztonságos távelérés)
  • 80 – HTTP (titkosítatlan web)
  • 443 – HTTPS (titkosított web)
  • 445 – SMB (Windows megosztás ⚠️)
  • 3389 – RDP (Windows távoli asztal ⚠️)

Az nmap megmutatja, melyik nyitott nálad.

🚀
